# DRESSFEAT — Modern Luxury MERN E-Commerce Platform

A responsive full-stack MERN (MongoDB, Express, React, Node.js) web application inspired by high-fashion atelier streetwear and the DRESSFEAT 2026 Collection.

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
cd backend
npm install
cd ../frontend
npm install
```

### 2. Run the Application
In terminal 1 (Backend API Server on port 5000):
```bash
cd backend
npm start
```

In terminal 2 (Frontend Client on port 3000):
```bash
cd frontend
npm run dev
```

Visit **http://localhost:3000** in your browser.
